# Phase 5 — Pre-ship gate (hosted proxy + auth + billing + packaging)

> **Scope:** Phase 5 is **the wall** Phase 4 kept pointing at. **Nothing ships to anyone — not one paying stranger — until every box here is checked.** This is what turns the Phase-4 app from "runs on my machine with my key in a `.env`" into "a stranger can pay, install, and use it without draining my API key or stealing my IP."
>
> **The one-line model:** the shipped app no longer holds the Anthropic key or the system prompt. A **hosted proxy** holds both, authenticates the caller (Supabase), checks they're paid (Stripe→Supabase), meters their usage, then forwards to Anthropic and streams back. The agent loop + tool dispatch + ExtendScript stay **local** (they drive AE) — only their *names* leak; the prompt + tool semantics + key live server-side.

> **Stack decided:** Cloudflare Workers (proxy) · Supabase (auth + DB) · Stripe (billing) · Cloudflare R2 (update feed). Rationale for each lives inline as `WHY:`.

---

## §A. Hosted LLM proxy — Cloudflare Workers (gates everything)
> Thin proxy: holds the key + injects the secret prompt/tool defs server-side; the loop stays client-side so each proxy call = **one** Claude response (stateless, short → serverless-friendly). **WHY Workers:** industry-standard for streaming LLM gateways, auto-scales, edge latency, cheapest; streaming wait doesn't count against CPU limit. **⚠️ escape hatch:** if Workers' V8-isolate runtime fights us, switching to an always-on Node box (Railway/Fly/Render) is a ~half-day job — the app only knows the proxy URL. Re-evaluate then.
- [x] **§A-0** **Four test surfaces survive Phase 5 — local-first, don't burn cloud to test.** The Phase-4 §B `CUBIC_ENV` switch (`app/src/main/config.ts`) is the lever; §A-8 only flips the *shipped* default to `prod`. Keep all four working:
    - **MCP-only** — AE bridge standalone via Claude Code / integration tests. **No Anthropic token spend.** Unchanged by Phase 5 (the bridge never touches the proxy).
    - **direct-local** _(default `npm run dev`, today's flow — STAYS the default)_ — `CUBIC_ENV=local` → agent loop calls Anthropic directly with `ANTHROPIC_API_KEY` from `server/.env`. Fully on-device: no Worker, Supabase, or Stripe. §A-3 makes the client *fork* (proxy vs direct), it does **not** delete this branch.
    - **full-stack-local** — `CUBIC_ENV=prod` + `CUBIC_PROXY_URL=http://localhost:8787` → exercises the real proxy/auth/meter/billing path against **local emulators** (`wrangler dev` + `supabase start` + Stripe test mode). Tests the whole gate with **zero real cloud/Supabase compute** (test-mode tokens only). **Rule: develop every §A–§C component against its emulator here first**, before any deploy.
    - **prod** — `CUBIC_ENV=prod` + prod `CUBIC_PROXY_URL` → real deployed infra. Emulators don't cover OAuth redirects, webhook timing, Worker cold-starts, signing/Gatekeeper, real install → the §G-3 clean-machine E2E (ideally a second person's laptop) stays **mandatory**.
- [x] **§A-1** **Move the crown jewels server-side** — relocate `server/ai/src/prompt/rules.ts` (`STATIC_RULES` + `{{COMMAND_CATALOG}}`) **and** all tool descriptions/`input_schema` into the Worker. These must **never** ship in the binary. Client keeps only tool **names** + dispatch + ExtendScript (unavoidably local — they run in AE).
- [x] **§A-2** **Worker = Anthropic-shaped passthrough** — accept a messages request (no system, no tools), inject system prompt + full tool catalog + `ANTHROPIC_API_KEY` (Worker secret), forward to `api.anthropic.com`, **stream the response body straight back** (`new Response(upstream.body)`). Hand-rolled `fetch`, no Node SDK.
- [x] **§A-3** **Repoint the client** — replace the direct `new Anthropic({apiKey})` call (`server/ai/src/llm/anthropic.ts`) with a call to the proxy: `baseURL` = proxy URL, auth = Supabase access token (custom header), **no API key on device**. Client still sends `messages` + volatile `<live_ae_state>`; receives `tool_use`, dispatches locally as today.
- [x] **§A-4** **Verify Supabase JWT** (stateless, no round-trip) on every request → reject unauthenticated callers before spending anything. _(DONE — WT-PROXY-GATING: `proxy/src/auth.ts`, local JWKS verify via `jose`, asymmetric algs pinned + iss/aud/exp checked; token rides the `userChat` frame → per-request `Authorization` header.)_
- [x] **§A-5** **Entitlement check** — read the user's row from Supabase `subscriptions`, **cached ~30–60s**. **WHY fresh:** every allowed request spends *my* money, so a canceled/abusive user must lose access in seconds, not after a 1-hr token. (→ §C) _(DONE — `proxy/src/entitlement.ts`: `get_entitlement` RPC as service-role, ~60s in-memory cache, **strict fail-closed** on lookup failure → 503, no stale-serve.)_
- [x] **§A-6** **Usage metering** — after each response, read Anthropic's token counts → write usage to Supabase + **deduct from the user's monthly allowance**; reject when over cap. (Read=gate, write=meter, both here.) _(DONE — `proxy/src/metering.ts`+`usage-parse.ts`: `tee` the response, cost-cents via proxy-side pricing map, async `ctx.waitUntil` → new `record_usage` RPC. Cap is soft: gate on cached entitlement, meter after.)_
- [x] **§A-7** **Per-user rate-limit + abuse guard** — cap requests/min per user to bound runaway/abuse spend on the single key. _(DONE — Cloudflare native Rate Limiting bindings: `RATE_LIMITER` (per user) + `IP_RATE_LIMITER` (pre-auth per IP), on top of the free edge DDoS layer.)_
- [ ] **§A-8** **Flip the Phase-4 §B env-switch** — point the shipped app at the prod proxy URL (was `localhost`). _(Deferred to the real-deploy capstone: keep direct-local the `npm run dev` default; test prod via explicit `CUBIC_ENV=prod`+`CUBIC_PROXY_URL` override, flip the shipped default only at real ship.)_
- [x] **§A-9** _(bonus)_ **Prompt-cache win** — all users share one key + identical system-prompt/tool prefix → high Anthropic prompt-cache hit rate. Keep the `cache_control` breakpoint on the static prefix when injecting.
